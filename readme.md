# ☕ Starbucks Landing Page Clone

Uma recriação responsiva e interativa de uma landing page clássica da Starbucks. Este projeto foi desenvolvido com foco em fidelidade visual, estruturação semântica e usabilidade em diferentes dispositivos, unindo boas práticas de interface com desenvolvimento Front-End.

## 📌 Sobre o Projeto

O objetivo deste projeto foi construir uma interface limpa e moderna, aplicando conceitos avançados de CSS (Grid e Flexbox) e implementando interatividade com JavaScript puro (Vanilla JS). O layout adapta-se perfeitamente a telas de desktop, tablets e smartphones, oferecendo uma experiência de navegação contínua.

## ✨ Funcionalidades e Destaques

*   **Design Totalmente Responsivo:** Utilização estratégica de Media Queries para adaptar o layout (de 2 colunas para 1 coluna em dispositivos móveis).
*   **Menu Inteligente:** 
    *   No Desktop: Navegação horizontal integrada ao cabeçalho.
    *   No Mobile: Menu "hambúrguer" interativo com transição suave, controlado via JavaScript.
*   **Organização CSS:** Nomenclatura de classes inspirada na metodologia BEM (Block, Element, Modifier) para facilitar a manutenção e escalabilidade do código.
*   **Acessibilidade e Semântica:** Uso correto de tags HTML5 (`<header>`, `<nav>`, `<section>`, `<footer>`) e atributos `alt` em imagens.

## 🛠️ Tecnologias Utilizadas

*   **HTML5**
*   **CSS3** (Variáveis, Flexbox, CSS Grid)
*   **JavaScript (ES6+)** (Manipulação de DOM e Event Listeners)
